# Urbanview — five mascot samples

Generated using the built-in `image_gen` tool, preserving the existing waving mascot as the identity reference. These are style exploration images with a warm-white background, not transparent production assets. No webpage images have been replaced.

| Sample | Direction | File |
| --- | --- | --- |
| 01 | Retro arcade pixel style | [01-8bit-arcade.png](01-8bit-arcade.png) |
| 02 | Pixel paste-up with yellow rim and blue offset shadow | [02-pixel-pasteup.png](02-pixel-pasteup.png) |
| 03 | Angular stencil and spray texture | [03-street-stencil.png](03-street-stencil.png) |
| 04 | Comic ink and halftone print texture | [04-halftone-comic.png](04-halftone-comic.png) |
| 05 | Loose paint-marker street illustration | [05-marker-graffiti.png](05-marker-graffiti.png) |

The exact final prompt for each sample is recorded in [prompts.json](prompts.json). All five preserve the warm hair, tan ears/tail, rectangular glasses, grey jacket, plaid shirt, red collar, and sneakers. The first two explore a pixel aesthetic; they are generated concept illustrations rather than validated low-resolution animation sprites.

Recommended direction for the current site: 02, which pairs most directly with the fluorescent yellow/electric blue visual system and pixel contact icons. 05 is the alternative when a looser street-art character is preferred.
